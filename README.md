# Kuis 8 Kunci

Bahasa Indonesia / Indonesian + English (dua bahasa di satu berkas)

====================

Deskripsi (Indonesia)
---------------------
Kuis 8 Kunci adalah aplikasi kuis interaktif berbasis mobile untuk kebutuhan Pengabdian Kepada Masyarakat (PKM). Aplikasi ini terhubung langsung ke Supabase dari sisi frontend (tanpa memuat folder backend dalam repositori ini).

Build & Run (Flutter)
----------------------
Jalankan dari root proyek (folder `Kuis 8 Kunci`):

```bash
# masuk ke folder project
cd "Kuis 8 Kunci"

# pasang dependensi
flutter pub get

# jalankan di emulator / device
flutter run

# untuk menghasilkan APK (release)
flutter build apk --release
# umumnya hasil ada di: build/app/outputs/flutter-apk/app-release.apk
```
